**MedScan** is a full-stack web portal for radiological centers and medical clinics. It allows uploading patient records with DICOM/Image scan files, reviewing diagnostic lists, viewing summary drawers, and generating printable A4 clinical reports.

---

## ✨ Features

- 📤 **Patient CT Upload**: Upload patient details along with scan files.
- 📋 **Clean Master Dashboard**: Structured table with recommended action triggers.
- 📑 **Quick Summary Drawer**: Side panel for quick patient diagnosis summary.
- 📄 **Printable A4 Diagnostic Report**: Official medical report format with doctor signature sections.
- 🖨️ **PDF Export**: Direct browser-level printing for report exports.

---

## 🏗️ Tech Stack

- **Frontend**: React.js, Axios, HTML5
- **Backend**: Node.js, Express.js, Multer
- **Styling**: Modern Clean UI System
